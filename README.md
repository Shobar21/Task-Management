# Taskmaster

Taskmaster is a task management website that allows users to create, edit, delete, and assign tasks. It also lets users set task priorities (High, Medium, Low) and track task progress efficiently.

## Features

- **Task Management:** Create, edit, delete, and assign tasks.
- **Task Priority:** Set task priorities as High, Medium, or Low.
- **Progress Tracking:** Monitor task progress.
- **User-Friendly Interface:** Built with a modern and intuitive design.

## Technologies Used

Taskmaster is built using the **MERN stack**:  
- **Frontend:** React.js  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  

## How to Run the Project

### Server Side
1. Clone this repository and navigate to the `server` folder.  
2. Run the server using the following command:
